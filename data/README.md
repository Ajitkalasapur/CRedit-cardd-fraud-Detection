# Data

This folder is where the dataset goes. It is not stored in the repository because the file is about 150 MB, larger than GitHub's file size limit.

1. Download **creditcard.csv** from Kaggle: [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
2. Save it here as `data/creditcard.csv`

The dataset was collected and released by the Machine Learning Group at Université Libre de Bruxelles (ULB). See the Kaggle page for license and citation details.
